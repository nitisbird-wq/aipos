# Content library

One subfolder per piece, named by slug (matching the research doc it came from). Each channel draft
lives at `<slug>/<channel>.md`, where `<channel>` is one of: `youtube-script`, `substack`, `x-post`,
`slides-outline` — see `rae-writer`'s output contract in `.claude/agents/rae-writer.md`.

Track status on `ai-team/pipeline/board.md`, not by renaming or moving these folders.
